# Kitchen AI Designer — установка Windows

## 1. Установить Ollama
Установите Ollama для Windows с официального сайта Ollama. После запуска Ollama она должна слушать локальный API `http://127.0.0.1:11434`.

Затем скачайте любую модель, которую ваш ПК способен запускать. Package 01 не зашивает имя модели: интерфейс показывает фактически установленные модели.

## 2. Установить Kitchen AI Designer
Запустите `KitchenAI_Setup.exe` от обычного пользователя. Установщик запросит административное подтверждение Windows, потому что устанавливает приложение в Program Files.

## 3. Первый запуск
1. Откройте Kitchen AI Designer.
2. Нажмите «Обновить модели».
3. Выберите локальную модель Ollama.
4. Нажмите «Проверить железо» и при необходимости измените Lite/Standard/Pro.
5. Создайте проект.
6. Напишите описание кухни.
7. При необходимости добавьте план/фото.
8. Нажмите Ctrl+Enter или «Отправить».

## 4. Где находятся проекты
```text
%LOCALAPPDATA%\KitchenAI\Projects
```

В проекте сохраняются `project.kitchen.json`, ссылки на вложения, версии и чат.

## 5. Offline
После установки Ollama и локальной модели чат Package 01 не требует платного API и не отправляет проект во внешний сервис.

## 6. Если Ollama не найдена
Проверьте, что Ollama запущена и локальный адрес `http://127.0.0.1:11434` доступен. Если используется другой адрес, задайте переменную среды:
```powershell
$env:KITCHENAI_OLLAMA_URL='http://127.0.0.1:11434'
```
и запустите приложение заново.

## 7. Ограничения Package 01
Package 01 — рабочий фундамент: чат, проекты, память, вложения, Ollama и hardware check. Точная Blender-геометрия, материалы, рендер и object-level editing относятся к последующим пакетам согласно ТЗ.
